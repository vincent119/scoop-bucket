# scoop-bucket

Vincent 的個人 Scoop Bucket，收錄自訂 Windows 應用程式安裝清單。

Personal Scoop bucket containing custom Windows app manifests.

## 安裝 / Installation

```powershell
scoop bucket add vincent https://github.com/vincent119/scoop-bucket
```

## 應用程式 / Apps

| 名稱 / Name | 說明 / Description |
| --- | --- |
| pulumiGo | A CLI wrapper for Pulumi infrastructure-as-code workflows, written in Go |

## 使用方式 / Usage

新增 bucket 後，使用以下指令安裝應用程式：

After adding the bucket, install apps with:

```powershell
scoop install pulumiGo
```
